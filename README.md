# FX Rates — курсы валют банков РФ

Скрапер собирает актуальные онлайн-курсы обмена валют с сайтов российских банков
и выводит их в виде таблицы для сравнения.

## Что делает

- Загружает курсы покупки и продажи с сайтов **ВТБ** и **Альфа-Банка**
- Валюты: **USD, EUR, CNY, KZT, GBP** (к рублю)
- Приводит данные разных банков к единому формату
- Учитывает курсы ВТБ по диапазонам сумм («до 100», «до 100 000» и т.д.)
- Выводит таблицу для сравнения банков

## Запуск

Требуется Python 3.12.

```bash
cd scraper
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

pytest -v            # тесты
python -m fxscraper  # получить актуальные курсы
```

Пример вывода:

```
BANK   CCY         BUY       SELL  TIER
ALFA   USD       79.63      85.83
VTB    USD   80.800000  84.950000  0 - 100.00
VTB    USD   80.900000  84.850000  100.00 - 100000.00
```

```
│   ├── __main__.py      # Точка входа

│       ├── base.py      # Общий интерфейс банка, настройка TLS

│       └── alfa.py      # Парсер Альфа-Банка

└── certs/               # Сертификаты Russian Trusted Root CA
```

## Технические решения

- **Decimal вместо float** — денежные значения хранятся без потери точности.
- **Проверка данных** — если курс покупки выше курса продажи, парсер выдаёт ошибку.
- **Время в UTC** — время ВТБ (без часового пояса) интерпретируется как московское.
- **Корректный TLS** — сертификат Russian Trusted Root CA добавляется в SSL-контекст
  вместо отключения проверки сертификатов.
- **Тесты без интернета** — парсеры проверяются на сохранённых ответах банков.

## Примечание

Учебный некоммерческий проект. Используются только публичные данные,
один запрос к каждому банку за запуск.
